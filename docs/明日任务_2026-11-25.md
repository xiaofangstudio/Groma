**实现口径（默认方案，不再另开设计会）**

- 在 `PathAnchor` 增加可选稳定 `vertexId?: string`；同一 `vertexId` 出现在多条轮廓里即视为共享顶点。旧工程无 `vertexId` 按独立锚点处理，加载不受影响。
- 新建锚点/普通插点生成唯一 id；`Alt`+点已有锚点起分支时，新轮廓首锚复用该锚点的 `vertexId`。
- 编辑层命中后，凡是相同 `vertexId` 的锚点一起改 `x/y/in/out`；事务仍是一条撤销。
- 暂不做完整 `VectorRegion` / 区域填充 / 任意图边；本轮只解决“共享点 + 多轮廓分支”这个最小内核。
- schema 只校验 `vertexId` 为非空字符串（若存在），重复 id 允许。

**入口**
