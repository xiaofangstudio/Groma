# Groma 地基规格（C100）

> README 第零章的落地细则。M0a 按本文实现，逐条配单测；本文不改，代码不许改口径。

## 1 场景图不变量

- 每页一个 `root` 容器，节点 id 全局唯一（12 位 nanoid），创建后永不改。
- `parent.children` 的顺序就是 z 序（后面的画在上面），不另存 zIndex。
- 三向一致：`node.parentId` 与 `parent.children` 含该 id 必须同时成立，不许孤儿、不许双父。
- 无环：任何节点不能是自己的祖先；重挂载前先做祖先检查。
- 几何存局部坐标：`x/y/w/h` 相对父内容原点，`rotation` 绕自身中心，`flipH/flipV` 先翻后转；**不存世界矩阵**，一律派生。
- `group` 无自身尺寸，包围盒由子级算；`frame` 有固定 w/h，可开 `clipContent`。
- `visible/locked` 只影响渲染与命中，不参与几何与约束计算。
- 约束只在父 frame 改尺寸时求值，结果写回子级 x/y/w/h，不保留中间态。

## 2 坐标与矩阵

- 世界坐标 f64、单位 px、y 向下；1x 导出即逻辑像素。
- 视图 = scale + tx/ty；局部→世界逐级乘父变换，世界→局部用逆矩阵。
- DPR：canvas 物理尺寸 = CSS 尺寸 × devicePixelRatio，变换里乘 DPR，文字按物理像素设字号。
- 0.5px 对齐只给 1px 描边与 1px 网格线，偏移 0.5/DPR；其他一律不对齐。
- 滚轮以光标为锚：`tx' = px − (px − tx) × (s'/s)`，y 同理。

## 3 命令与撤销

- 一切变更 = `Command { label, do, undo, coalesceKey? }`；`applyCommand` 是唯一入口。
- 事务：`begin()` 收集子命令 → `commit()` 压栈；异常 `rollback()`，半截变更不许留在树上。
- 合并：同 `coalesceKey` 且间隔 < 300ms 合并为一步（滑杆、拖拽、连续输入）。
- 栈：环形 200 步；撤销后可重做，一旦有新提交立即清空 redo。
- 存反向补丁（path + before/after），不存整树快照；结构变更只记最小子树。
- 禁止 UI 直接 mutate 节点：ESLint 规则 + dev 期 `Object.freeze` 双重拦截。
- 每次 commit 递增 `doc.version`，供渲染脏标记与自动保存去抖使用。

## 4 渲染管线

- 三层 canvas：`grid`（背景/网格/参考线，视图或设置变才画）、`content`（场景内容，按视口裁剪）、`overlay`（选框/手柄/对齐线/框选矩形，每帧只清这一层）。
- 脏标记：节点变更标脏其世界包围盒；视图变更全量重画 content。
- 剔除：页级网格索引，按视口 + 8px 余量取候选；不可见节点不进 draw。
- 子树位图缓存留接口（frame 级），一期可不开；缩放跨 2× 档或子树变更时失效。
- 文本 `measureText` 缓存 key = fontId + size + weight + letterSpacing + content；autoWidth 与 fixed 两套换行规则。
- 绘制顺序 = 树后序；混合模式映射到 `globalCompositeOperation`；背景模糊必须离屏 + clip。
- 每帧预算 16.6ms：content ≤ 10ms、overlay ≤ 2ms，React 不参与画布每帧。

## 5 序列化与迁移（当前实际口径）

- `project.json`：`{ format:"groma", formatVersion:1, name, createdAt, updatedAt }`（见 `src-tauri/src/main.rs`）。
- `scene.json`：`{ version:1, name, pages:[{ id, name, rootId, background }], nodes:{ [id]: SceneNode } }`；页面根节点 `type="page"`、`parentId=null`。
- 节点字段按 `src/core/types.ts`；当前 `validateDoc` 会拒绝父子不一致、重复归属、环、孤儿、非有限数字和非法填充。
- 当前写法是紧凑 `JSON.stringify`，键序随对象插入序；**尚未实现键排序/4 位小数规范化**，所以不宣称“字节级规范化”，只保证同一文档往返语义一致（100 次 bench 已测）。
- 迁移：目前只有 version 1；`migrate(doc)` 尚未实现，遇到未知版本直接拒绝并给中文错误。
- 资产：目录已预留 `assets/`，图片填充尚未实现。

## 6 存储与恢复（当前实际口径）

- 原子写：Rust 侧写 `.tmp` 后替换；MCP 侧也是 `.tmp` 后替换。
- 自动保存：前端内容变更去抖 **600ms**；Rust 只做落盘。同一工程的多次保存已在前端串行化，旧保存不会覆盖新保存。
- 快照：每次保存前复制一份到 `snapshots/`，保留 20 份；文件名 `<时间戳>-<随机>.json`，不是规划里的 `YYYYMMDD-HHmm-<reason>`。
- 崩溃恢复：`session.lock` 与启动恢复提示尚未实现；当前靠快照手工恢复。
- 只读目录、磁盘满、损坏 JSON：前端捕获后把底栏切成“保存失败”，不假装成功；损坏场景在加载时被 `validateDoc` 拒绝并给前三条错误。

## 7 性能预算

| 环节 | 预算 |
| --- | --- |
| 命中 | ≤ 1ms @ 5000 节点 |
| 单帧绘制 | ≤ 10ms @ 5000 节点、100% 缩放 |
| 撤销单步 | ≤ 50ms（最坏树） |
| 50MB 工程读入 | ≤ 3s（含缩略图重建） |
| 内存 | 空工程 ≤ 300MB；50MB 工程 ≤ 1.2GB |
