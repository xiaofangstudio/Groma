# Groma 品牌标识

> 版本：1.0 ｜ 2026-11-22 ｜ 主标：`frame-node`（画板四角 + 定位节点）

## 1. 为什么换掉 GR

旧标是黄色圆角方 + 墨色 `GR` + 两道“小方眼睛”。它的问题是：

- 字母缩写只说明名字，不说明 Groma 是**画界面**的工具；
- “小方眼睛”是角色记号，放在工具图标里会抢走产品语义；
- 两道竖条在 16px 下会糊成噪点，反而不如纯几何稳。

新标不再使用字母，也不使用小方。它只做一件事：**用四个角围出一块画板，在中心放一个可拖动的控制点。**

这正好对应 Groma 的名字：古罗马测绘架放线、定界、规划城市；Groma 用来放线、定界、规划界面。四角是画板边界，蓝点是第一个落下的定位节点。

## 2. 构造

以 1024×1024 为母版：

| 部件 | 几何 | 颜色 |
| --- | --- | --- |
| 底板 | `x=64..960`，`y=64..960`，圆角半径 `224` | 主黄 `#F2B705` |
| 四角取景框 | 框边 `x1=256`、`x2=768`，笔宽 `52`，每臂 `138`，圆头 | 墨色 `#181203` |
| 中心节点 | `128×128`，位于 `448..576`，圆角 `32` | 蓝 `#2F6BFF` |

透明区留在 squircle 四角外，Windows 任务栏、窗口、网页 favicon 都按同一张母版出图。

## 3. 读法

- **黄底**：继承 Groma 已有主黄，和工作室其他产品一样先有一个能认出的色块。
- **四角**：不是“扫描框”，是设计画板的四个角；开口是为了让中间的节点成为主角。
- **蓝点**：选中、拖动、定位。它是 Groma 里最常发生的一个动作。
- **三色**：黄、墨、蓝。没有渐变、没有阴影、没有描边、没有字母。

## 4. 小尺寸

小尺寸不靠缩图，按目标像素单独绘制：

| 尺寸 | 框线 | 中心节点 |
| --- | --- | --- |
| 16 | 1.8px | 2.8px |
| 24 | 1.8px | 3.0px |
| 32 | 1.8px | 4.0px |
| 48 | 2.4px | 6.0px |
| 64 | 3.3px | 8.0px |
| 128 | 6.5px | 16px |
| 256 | 13px | 32px |
| 1024 | 52px | 128px |

16px 下仍能读出“四个角 + 一个点”；低于 16px 不再使用这个标，改用纯色块或文字。

## 6. 使用规则

- **留白**：标外至少留 `64/1024` 的透明边；不要贴着文字或容器边缘放。
- **最小尺寸**：应用图标 16px；界面内联 20px；再小用文字。
- **比例**：只允许等比缩放，不拉伸、不压扁。
- **颜色**：只使用母版的黄 / 墨 / 蓝；不做单色反白、不加渐变、不加阴影、不加外描边。
- **背景**：放在浅色或中性深色底上；不要压在照片、复杂插画、强纹理上。
- **禁止**：不加 `GR`、不加小方眼睛、不加眼睛/嘴/头发、不旋转、不加透视、不把四角改成实心方块。

## 7. 和工作室家族的关系

- **Strata**：青蓝 squircle + UI 卡片 + 小方；强角色、强场景。
- **Chapter**：橙色手绘打开书本；强物件、强手作感。
- **Scheda**：蓝色 squircle + 白色文档页；强物件、强文档语义。
- **Groma**：黄色 squircle + 四角画板 + 蓝点；不强角色，强“画板 + 控制点”。

共同点不是“都有一只小方”，而是：**一个高识别色块 + 一个扁平图形 + 一个能在小尺寸读出的轮廓**。Groma 在这一层里，不靠字母，也不靠角色。

## 8. 已否掉的方向

| 方向 | 为什么不用 |
| --- | --- |
| `survey-cross` | 四段胶囊围蓝点，缩小后像 loading / 更多操作，不像画板 |
| `artboards` | 两张错位画板 + 蓝点，读起来像“复制 / Duplicate” |
| `paper-frame` | 奶油画板 + 四角框 + 蓝点，缩小后像扫描 / 相机对焦框 |
| `frame-grid` | 四角框 + 十字辅助线，放大像瞄准镜，缩小线消失，语义反而更窄 |

最终保留 `frame-node`：开口四角给出画板边界，中心节点给出“可操作”的动作，16px 仍有轮廓。
