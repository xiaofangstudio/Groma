# 超越 Figma：Groma 的差异化路线

> 基线不只 Figma 免费版：免费版能做的逐项补齐，付费版（Dev Mode、Variables、组件库、原型、分支/命名版本）也要能对上。
> 这份文档回答两个问题：**Groma 还要补哪些付费能力，以及凭什么让人不用免费 Figma。**

## 1. 先看清对手的“垄断点”

Figma 的优势不是单个绘图工具，而是四件事捆在一起：

| 垄断点 | Figma 免费版 | Groma 现在的切口 |
| --- | --- | --- |
| 文件在云上 | 账号 + 云端工程，免费版有数量限制 | 本地 `.groma` 工程，离线可开，文件归用户 |
| 协作在云上 | 实时多人、评论、分享链接 | 不做云端协作；先把单机设计闭环做深 |
| 交付在云上 | 设计稿留在 Figma，开发去 Dev Mode / 插件取代码 | 设计稿直接生成本地可运行 HTML，设计即交付 |
| 能力在插件市场 | 高级导出、令牌、代码生成靠社区插件 | 原生内置 HTML / CSS 令牌 / MCP，不装插件 |

结论：**不和 Figma 拼“云协作”，用“本地 + 可运行交付 + 可编程”打它的付费墙和插件墙。**

## 2. Groma 已经比 Figma 免费版多什么

### 2.1 可运行 HTML 导出（本轮已落地）

- 导出弹窗第四种格式 `HTML`，和 PNG/JPG/SVG 同一个入口、同一套范围选择。
- 输出不是截图，而是独立 `.html`：文字仍是 `<div>` 文本，可选中、可复制、可被浏览器搜索；形状是 CSS 背景/渐变/圆角；路径是内联 SVG；图片是内嵌 data URL。
- 产物双击即可打开，不依赖 Groma、不依赖 Figma、不依赖服务器。
- Figma 免费版没有这个原生出口；Dev Mode 的代码面板是付费能力，且给的是代码片段，不是完整页面。

### 2.2 命名样式直接变设计令牌（本轮已落地）

- 右栏“样式”下方有“复制变量”与“导出令牌”。
- `填充 / 描边 / 效果 / 文本` 四类命名样式一次生成 `:root { --groma-... }`。
- “导出令牌”一次写 `<工程名> 设计令牌.css` 与 `.json` 到工程 `exports`，可进 Git、可被构建脚本直接读。
- 多填充按顶层到底层输出，纯色自动转 `linear-gradient`，保证多图层 CSS 值合法。
- Figma 免费版没有原生令牌出口；付费版 Variables 也是云端资产，不是可直接提交的本地文件。

### 2.2b 选中图层直接出 CSS（本轮已落地）

- 选中 Frame / 形状 / 图片 / 组，右栏“代码”段输出可直接粘的 CSS：定位尺寸、圆角、纯色/多渐变、描边、投影、模糊、文本字体。
- “复制 CSS”走可信用户手势，按钮即时反馈“已复制”。
- 这是 Figma 付费 Dev Mode 的代码检查能力，但 Groma 不需要切模式、不需要云端工程。

### 2.3 原生 MCP（已有 19 个工具）

- Groma 自带 stdio MCP，能读写工程、批量建画板、批量改节点、查询能力。
- Figma 没有官方原生 MCP；外部自动化通常要插件、REST API 或付费席位。
- 这条是“可编程设计文件”的地基，后续可长成“AI / 脚本直接产设计”的入口。

### 2.4 本地工程与版本快照

- 工程是目录：`project.json` + `scene.json` + `assets` + `snapshots`，可用 Git、可 diff、可备份。
- A05 已有快照与回滚，保留最近 20 份；选中旧快照显示“相对当前：+N / -M / ~K”及变化图层。
- Figma 免费版的版本历史能力受限，付费版命名版本/分支也在云端；Groma 的 diff 直接跑在本地工程上。

### 2.5 一站式，不导出后跳外部软件

- 图片裁剪、形状图片填充、SVG 导入、布尔、蒙版、效果、导出都在 Groma 内完成。
- 外部 Strata / Vexa 只保留“选区处理”的例外入口，不作为默认交付路径。
- Figma 免费版遇到位图精修、特殊矢量处理，仍然要出 Figma 去别的软件。

### 2.6 大画板引擎

- 600 画板 / 5,400 图层冷启动：500ms 内 150 张，4.2s 内补齐 600 张，p95 0.2–0.4ms，1 个 >16ms、0 个 >32ms。
- 这保证“本地工作台”不是只能开小文件；Figma 免费版在超大文件上受云端和渲染策略限制。

## 3. 付费版能力缺口与差异化排序

Figma 收费的核心不是“画图”，而是把 Auto Layout、组件库、Variables、原型、Dev Mode、分支/版本治理捆进团队工作流。Groma 要让人不用免费 Figma，至少得先做到“单人完整设计闭环不输付费版”，再用本地交付赢。

| 优先级 | 能力 | 为什么值得做 | 落地形态 |
| --- | --- | --- | --- |
| 已落地 | 设计令牌文件导出 | 免费版无原生 tokens 出口，付费 Variables 也锁云端 | `.css` + `.json` 写入工程 `exports` |
| 已落地 | 本地版本 diff | 免费版版本历史弱、不可脚本化 | 快照间节点增删改与子层顺序 |
| 已落地 | 选中图层 CSS 检查 | 付费 Dev Mode 能力 | 右栏“代码”段 + 复制 CSS |
| 已落地 | 自动布局一期 | 免费版有基础自动布局；Groma 用本地引擎补上方向、间距、四边内距、对齐与 Hug | 固定主轴 + Hug 主轴；未做 Fill/Fixed 全组合、换行、布局网格 |
| 已落地一期 | 组件 / 实例 | 免费版组件能力受限；团队复用靠付费库 | 主组件 + 实例 + 显式同步 + 同步全部 + 脱离；未做实时联动、Override、Swap |
| 已落地一期 | 组件变体 / 组件库 | 付费版的组件系统核心，不只是主组件和实例 | 变体集合并、属性值、新增变体、多属性组合矩阵、三属性以上其余属性筛选面、实例同集切换；本工程跨页组件库搜索/跳页/实例计数，本机最近 12 个工程的跨工程浏览、依赖检查、可迁移组件导入、从来源更新、来源状态检查、断开来源、单组件本地发布与版本订阅；实例覆盖支持实例子层文字/填充/尺寸等改动在同步后重放并可逐层重置；组件替换保留位置并沿同名同类型覆盖。未做库级批量发布、版本回滚与变更日志 |
| 已落地一期 | Variables / 多 Mode | 付费版核心，设计令牌只有变量没有模式 | 颜色/数值/字符串/布尔变量，Light/Dark 等 Mode，填充、描边色、圆角、描边宽、自动布局间距、内边距与字号绑定，切 Mode 批量刷新；同类型变量可跨集合引用，沿链解析目标当前 Mode；未做批量导入/导出 |
| 已落地一期 | 原型与演示 | 免费版原型有限，付费演示是评审入口 | 节点点击目标、右栏原型段、顶栏演示、本地播放器、百分比热区、返回栈、Esc；未做拖拽/悬停/定时/Overlay/Smart Animate/设备框/分享 |
| P1 | PDF / ZIP 导出 | 免费版导出格式有限 | 多页 PDF、整包 ZIP（含 assets 与 HTML） |
| P1 | 离线字体嵌入 | 云端字体依赖账号与网络 | HTML 导出时字体子集转 data URL 或随包附带 |
| P1 | 单文件可移植工程 | Figma 工程绑云端 | `.groma` 打包成单文件，图片/字体/场景一体 |
| P1 | MCP 渲染/导出工具 | Figma 无原生 MCP | MCP 增加 `render_html`、`export_svg` 等工具 |
| P2 | 代码感知组件 | Figma 组件与代码是两套 | 组件直接带 HTML/CSS 产物，改设计即改代码 |

## 4. 不做的事（当前红线）

- 不做账号、云端同步、实时多人、评论。
- 不做 FigJam 白板、Slides、Sites、社区插件市场。
- 不做把“云协作”当卖点；这些是 Figma 的强项，不是 Groma 的切口。
- 不为了差异化牺牲 Figma 基线：Auto Layout、组件/变体、变量、原型、Dev Mode 仍然要补。

## 5. 本轮结论

- **已经多出来的**：原生可运行 HTML 导出、令牌 `.css/.json` 落盘、选中图层 CSS 检查、本地版本 diff、自动布局一期、组件一期（主组件/实例/同步/脱离）、原型一期（点击跳转/本地演示）、原生 MCP、本地工程/快照、600 画板引擎。
- **P0 已收口一期**：组件变体、本工程跨页组件库、Variables 多 Mode 已进真实 EXE；不拿“有一期”当“全对齐”，下一刀补库级发布/版本回滚/变更日志与变量批量导入/导出，仍不横铺。
- **判断标准**：不是“功能数量比 Figma 多”，而是“用户能不能在 Groma 里少开一个网页、少装一个插件、少做一次手工搬运”，同时基础编辑不输免费版。
