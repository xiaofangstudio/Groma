# 三款主力的界面典范与细节（Strata / Scheda / Chapter）

> 目的：Groma 的界面不重新发明，把已经证明「能当主力」的三款吃透，再套到专业编辑器上。
> 每条都标了来源（数值都是从各自源码/README 量的），实现时按条对照。

## 一 三款各自的性格与共同骨架

| 软件 | 性格 | 骨架 |
| --- | --- | --- |
| Strata | 冷工具：信息密度高，但每一栏都有秩序 | 顶栏 36 → 标签条 30 → 工具轨 / 选项栏 42 + 视口 / 右栏 326 → 状态栏 24 |
| Scheda | 阅读器：留白优先，一屏只干一件事 | 自绘标题栏 54 → 正文 / 目录侧栏（逻辑宽 ≥860 才出现） |
| Chapter | 内容型：氛围服务写作，但结构仍然清楚 | 顶栏 44 → 左栏 264 → 正文 / 右栏 320–372 |

共同点（也是「能当主力」的底层条件）：

- 单窗口、本地文件、零账号、零网络、关窗即退。
- 都有欢迎页/书架，都有空态引导，都有最近打开。
- 都有完整的设置持久化与快捷键体系。
- 都不靠「功能列表」撑场面，主链路（打开→编辑→保存→导出）真的跑通。

## 二 规范数值（工具类与阅读类不是一套）

| 令牌 | Strata | Chapter | Scheda（阅读） | Groma 取法 |
| --- | --- | --- | --- | --- |
| 圆角 | 6/8/12/16/20/999 | 6/8/12/16/22/999 | 默认 18 | 6/8/12/16/999 |
| 间距 | 4/8/12/16/24/32/48/64 | 同 Strata | 卡片内 18–22 | 4 的倍数 |
| 字号 | 12/13/14/16/20/26/34 | 同 Strata | 正文 16、行高 1.75、段距 14 | 11（元数据）12/13/14/16/20/26 |
| 控件高 | 34 / 40 | 32 / 38 | 32 药丸 | 28 图标 / 34 主控 |
| 面板 | 右栏 326（<1180 收 290） | 右栏 320/372 | 无固定栏 | 300（1280 档） |

结论：**工具类更紧（圆角 6–16、控件 32–34、字号 12–14），阅读类更松（圆角 18、行高 1.75）**。Groma 是工具，跟 Strata / Chapter 的口径，不跟 Scheda。

## 三 二十条值得抄的细节

1. **启动页与欢迎页同底色**，切换不闪白；启动页最短 400ms、最长 800ms（Strata Splash / BootScreen）。
2. **欢迎页左侧入口 + 右侧最近卡片**；Strata 用 `minmax(0,1.1fr) minmax(0,1fr)`、最大宽 1180、窄于 940 收成单列（`StartPage.css`）。
3. **空态三件套**：线稿插画 / 一句说明 / 一个主按钮，不拿空白面板当空态。
4. **单行文本一律省略**：`min-width:0 + nowrap + ellipsis`，全名进 `title`（Strata 标签名、Chapter 章节名）。
5. **标签条横向滚动但不显示滚动条**：`overflow-x:auto` + 滚动条高度 0（Strata `.editor-tabs`）。
6. **面板可折叠成 36px 图钉条**，右栏折叠后画布立刻变大，不是简单隐藏（Strata `RightDock` 36px 轨）。
7. **分组标题固定 36px + 右侧折叠箭头**，组与组之间 16px，不靠分割线堆叠。
8. **控件三档高度**：26 紧凑（标签内按钮）、28 图标、34 主控；不要一个 40px 大按钮混在小面板里。
9. **数字输入可拖、可滚、可直填**：按住左右拖改值，Shift 精细、Alt 加速（Strata `NumericField` / Reelix 后期补的 ScrubNumber）。
10. **焦点环不加位移**：`focus` 只加 2px ring，不缩放不抖动。
11. **状态栏只读信息**：24–26px，坐标与尺寸用 `tabular-nums`，不放按钮。
12. **Toast 深墨底白字、3 秒、底部居中**，不遮当前操作区（Strata `.toast`）。
13. **窗口规矩**（Scheda 最完整）：永不置顶；DPI 变化只换绘制比例、不动窗口尺寸；四边四角都能拖（边 8pt / 角 14pt）；最大化不出工作区；先算好尺寸再显示，开窗不抖。
14. **未保存标记要可见**：标签上的小圆点 / 保存点脉冲；保存失败绝不显示「已保存」。
15. **记忆光标与滚动位置**：退出编辑再回来还在原处（Scheda 编辑锁）。
16. **图片查看器**：20%–800% 缩放、拖拽平移、适应窗口 / 原始大小 / 复制（Scheda）。
17. **键盘优先**：工具键 + `Ctrl` 系 + `Esc` 逐级退出；所有菜单项都能用键盘到达。
18. **设置是整页，不是小浮窗**：改一个滑杆立刻见效并落盘（Scheda `Ctrl+E` 设置页；Strata 偏好设置）。
19. **系统集成**：文件关联、双击打开、启动参数带文件、多尺寸图标（Strata `.strata` / Scheda `.md`）。
20. **关于页有版本、许可、仓库入口**，不藏在 Help 菜单深处。

## 四 动效：工具型克制，内容型才铺氛围

**Strata（工具型，Groma 跟这套）**

- 基调：`--dur-fast 120 / --dur 180 / --dur-slow 280 / --dur-in 220 / --dur-out 150`（`tokens.css`）。
- 精简档：`--dur-in 140 / --dur-out 100 / --dur-fast 90 / --dur 120 / --dur-slow 160`，位移幅度 `--motion-amp: 0`（只留淡入）。
- 关档：动画与过渡统一 1ms，`scroll-behavior: auto`。
- 原则：弹性只用于「用户主动按下」的反馈，不用于被动出现的内容（`motion.css` 头部注释）。
- 系统 `prefers-reduced-motion` 自动降到精简档，不粗暴清零。

**Chapter（内容型，可借氛围、不可借时长）**

- 启动/欢迎 600ms `rise` 入场，弹窗 260ms 弹簧，Toast 240ms，场景切换 420ms 交叉淡入。
- 卡片边缘流光、金色丝线呼吸 26s——这些是「内容产品」的情绪价值，放到编辑器里会拖慢操作。

**Scheda（阅读型，借它的「瞬时」）**

- 目录跳转瞬时到位，不做慢滑；主题切换即时生效；滚动平滑但可关。
- 结论：阅读可以慢，工具必须快。

**Groma 的动效口径**

- 反馈 90–120ms，入场 180–220ms，退场 120–150ms；画布拖拽/缩放 0ms（跟手优先）。
- 弹性只给「按下」与「小弹层」，不给面板与画布。
- 三档：完整 / 精简 / 关，跟随系统降级；关档全部归零。
- 全应用只允许一处「氛围动画」：启动页 ≤800ms 淡出，其余一律服务操作。

## 五 为什么它们真的能投产（不是「功能表齐」）

1. **真实文件管线**：打开、保存、另存、最近、文件关联、启动带文件（Strata / Chapter / Scheda 都有）。
2. **自动保存 + 恢复**：Chapter 停手 1.4s、30s 兜底、失焦/切页/关窗强制存盘，快照保留 20 个；Strata 撤销栈还有 900MB 内存预算。
3. **导出闭环**：Chapter 出 TXT / Markdown / EPUB 3；Strata 出 PNG/JPG/PSD；导出物能在系统里正常打开。
4. **设置持久化**：Scheda 的 `settings.json` 记住主题、字体、背景、最近 24 条；Strata 偏好设置独立文件。
5. **体积与性能守得住**：Strata 裸 exe 8.63MB、NSIS 2.84MiB；Scheda 单文件 653KB；Chapter 走 Tauri 同一底座。
6. **零假功能 + 测试**：Strata 把「零假功能」写成最高优先级铁律，790 条测试；做不到的能力在 MCP 边界里如实列出。
7. **错误可见**：保存失败、格式不支持、依赖缺失都给中文原因与下一步，不静默降级。
8. **窗口与系统细节**：Scheda 的「永不置顶 / DPI 只换比例 / 拉不出屏幕」这类规矩，决定它能不能天天用。
9. **可发现性**：空态、快捷键药丸、菜单分组、Tooltip，用户不用读文档也能上手。
10. **语言与排版**：Chapter 十种语言含 RTL；Scheda 中英切换即时生效——不是「以后再说」。

## 六 Groma 的采纳与拒绝

**直接抄**

- Strata 的三栏骨架、36px 分组标题、右栏折叠、NumericField、状态栏、Toast、三档动效。
- Scheda 的窗口规矩、设置整页、光标/滚动记忆、图片查看器、文件关联。
- Chapter 的欢迎页叙事、空态、保存点、自动保存节奏。

**改造后用**

- 磨砂玻璃：参数用 Strata 的（`rgba(255,255,255,.62) + blur(22px) saturate(1.6)`），但画布区永远实底。
- 动效：Strata 的时长 + Chapter 的一处启动页氛围，别把 Chapter 的 600ms 入场搬进面板。
- 最近工程卡片：Strata 的两列网格 + Scheda 的「最多 24 条、可滚动」。

**明确不抄**

- Chapter 的 26s 呼吸、卡片流光（工具界面会分心）。
- Scheda 的阅读版心与 1.75 行高（编辑器要更紧）。
- Strata 的 24 工具轨（Groma 一期 11 个就够，多了就是 Reelix 式的堆）。
- 任何「42 效果 / 35 面板一屏铺开」的做法。

## 八 两个失败产品反推的红线

Reelix 和 FloatLab 不是「没写功能」，而是**功能和界面没有一起变成可用的产品**。这两款必须作为 Groma 的反面验收，而不是只写一句「吸取教训」。

### 8.1 Reelix：功能表很满，用户拿到的是旧壳

| 事故 | 事实 | Groma 红线 |
| --- | --- | --- |
| 交付的不是最新代码 | 用户双击的 exe 编于 13:10，最后一次改码在 16:44；包里的前端 `invoke` 出现 0 次，按钮根本没有后端可接 | 每轮验收只看 `src-tauri/target/release/groma.exe` 的实际时间与实跑结果，不看「源码里已经写了」；EXE 必须晚于全部源码，且用这份 EXE 截图 |
| 一进去直接落在编辑器 | 没有开场，工程还没定尺寸/帧率就把四区铺开 | 新建必须先选画板尺寸；没有工程时停在欢迎页，不露空编辑器 |
| 界面凌乱、到处拥挤 | 顶栏/面板/属性/效果没有统一一套尺寸，靠堆面板表达「专业」 | 只保留主链路需要的面板；一屏面板数量有上限；所有单行文本 `min-width:0` + 省略；三档窗口实拍无溢出 |
| 图标是脚手架默认 | `icon.ico` 只有 4,576 字节，是 Tauri 默认图标 | 应用图标、窗口图标、任务栏图标必须是 Groma 自己的多尺寸 `.ico`，不能混入默认图 |
| 只编 debug / dev 壳 | 没开 `custom-protocol` 时双击看到 localhost 拒绝连接 | 交付门禁统一走 `npx tauri build --no-bundle`，并实开 EXE 验证，不以 `cargo build` 代替 |
| 重活会假死 | 解码/合成/追踪在主线程上堆，界面没有「能取消、有进度」的边界 | 任何超过一帧的活都不许阻塞 UI；先有进度/取消/降级，再谈功能 |

### 8.2 FloatLab：架构野心跑在可用性前面

| 事故 | 事实 | Groma 红线 |
| --- | --- | --- |
| 先换心、再补全积木、最后才美化 | README 把界面重做放到三期，前期长期停在「能跑一点」的壳 | UI 不是最后一道油漆；每个功能落地时同时过空态、错误态、三档窗口和键盘路径 |
| 直接搬构建产物当底座 | `参考/` 里是 17MB webpack 产物，改不动逻辑，只能读布局 | 不把「看起来能跑」的第三方成品当自己的地基；核心交互必须在我们自己的代码里可测、可改 |
| 开发噪音长期不收敛 | `devserver.log` 3.39MB、`devserver.err.log` 2.73MB、`build.log` 1.29MB | 构建/运行日志不得进交付目录；每次 gate 只留最终结论，错误必须收敛成可读的一条 |
| 多套视觉语言并置 | 上游 Scratch 壳 + 冰蓝玻璃 + 自定义舞台，各自为政 | 全应用只有一套令牌；颜色只做强调，不靠第二套主题救场；圆角/字号/控件高只能从令牌来 |

### 8.3 Groma 的「能用」定义

1. 双击 EXE 能进欢迎页；新建时能选尺寸；进入编辑器后能画、能选、能改、能撤销、能保存、能导出。
2. 界面上每一个可见按钮都有真实行为；做不到的能力不出现，不写「稍后开放」。
3. 1440×900、1280×800、1040×680 三档窗口无横向溢出、无面板互压、无文字裁断。
4. 所有面板可滚动区独立滚动；单行文本省略；画布区永远不被面板挤到 0 宽。
5. 首屏不靠空白撑气场：欢迎页必须同时给出「新建」与「最近工程」，空态有明确下一步。
6. 视觉与 Strata / Chapter 同族：中性底 + 单一品牌强调色 + 6/8/12/16 圆角 + 12/13/14 主字号 + 4 的倍数间距。
7. 关窗后进程归零；保存失败绝不显示「已保存」；导出失败给中文原因。
8. 每轮交付都重新编 EXE、实开截图、关闭临时桌面；截图不是源码截图。
